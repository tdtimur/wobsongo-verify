# API Plan — REST API v3

## What this covers

The HTTP API layer: endpoints, request/response schemas, JWT auth, layered architecture (Route → Service → Repository), and testing strategy. The worker process and object storage are in `worker-plan.md`.

---

## Conventions

- Base prefix: `/api/v3`
- All responses: `application/json`
- All endpoints except `POST /api/v3/auth/token` require `Authorization: Bearer <jwt>`
- Pagination: `?page=1&page_size=20` (1-indexed)
- Errors: `{ "detail": str }` with appropriate HTTP status code
- OpenAPI v3 docs auto-generated by Litestar at `/schema`

## Request / Response Schemas

### `POST /api/v3/auth/token`

```
Request:
  { "password": str }

Response 200:
  { "access_token": str, "token_type": "bearer", "expires_in": int }

Response 401:
  { "detail": "Invalid credentials" }
```

### `GET /api/v3/documents`

```
Query params: page=1, page_size=20

Response 200:
  {
    "items": [
      {
        "id": str,
        "title": str,
        "filename": str,
        "num_pages": int,
        "chunks_stored": int,
        "ingested_at": str   # ISO 8601
      }
    ],
    "total": int,
    "page": int,
    "page_size": int
  }
```

### `GET /api/v3/documents/{id}`

```
Response 200:
  {
    "id": str,
    "title": str,
    "filename": str,
    "file_type": str,
    "file_size": int,
    "num_pages": int,
    "content_hash": str,
    "chunks_stored": int,
    "facts_extracted": int,
    "ingested_at": str
  }

Response 404:
  { "detail": "Document not found" }
```

### `DELETE /api/v3/documents/{id}`

```
Response 204: (no body) — cascades to document_chunks and verified_facts

Response 404:
  { "detail": "Document not found" }
```

### `POST /api/v3/jobs`

```
Request:
  { "title": str, "filename": str }

Response 201:
  {
    "job_id": str,
    "storage_key": str,
    "upload_url": str,    # presigned S3 PUT URL, 1-hour TTL
    "status": "pending"
  }
```

Admin uploads the PDF directly to `upload_url` — the app server is not in the upload path.

### `GET /api/v3/jobs`

```
Query params: status=pending|processing|done|failed (optional), page=1, page_size=20

Response 200:
  {
    "items": [
      {
        "id": str,
        "title": str,
        "filename": str,
        "status": str,
        "chunks_stored": int | null,
        "facts_extracted": int | null,
        "error_message": str | null,
        "created_at": str,
        "started_at": str | null,
        "finished_at": str | null
      }
    ],
    "total": int,
    "page": int,
    "page_size": int
  }
```

### `GET /api/v3/jobs/{id}`

```
Response 200: same shape as a single item in the list above

Response 404:
  { "detail": "Job not found" }
```

### `POST /api/v3/jobs/{id}/retry`

```
Request: (empty body)

Response 200:
  { "job_id": str, "status": "pending" }

Response 404:
  { "detail": "Job not found" }

Response 409:
  { "detail": "Job is not in failed state" }
```

Resets `status → pending`, clears `error_message`, `started_at`, `finished_at`.

### `POST /api/v3/verify`

```
Request:
  { "text": str, "language": str = "en" }

Response 200:
  {
    "post_id": str,
    "overall_verdict": "SUPPORTED" | "REFUTED" | "INSUFFICIENT_EVIDENCE" | "MIXED",
    "verdicts": [
      {
        "claim": str,
        "verdict": "SUPPORTED" | "REFUTED" | "INSUFFICIENT_EVIDENCE",
        "confidence": float,
        "reasoning": str
      }
    ]
  }
```

## Auth — JWT (HS256)

**Library:** `PyJWT` (add to core deps in `pyproject.toml`)

**Environment variables:**
```
WOBSONGO_JWT_SECRET       # HS256 signing secret — required, no default
WOBSONGO_ADMIN_PASSWORD   # compared at /auth/token
WOBSONGO_JWT_TTL_HOURS    # default: 24
```

**Token claims:**
```json
{ "sub": "admin", "iat": 1234567890, "exp": 1234567890 }
```

**Middleware** (`wobsongo/api/middleware/auth.py`):
1. Skip if path == `/api/v3/auth/token`
2. Read `Authorization: Bearer <token>` header → 401 if missing
3. `jwt.decode(token, secret, algorithms=["HS256"])` → 401 if invalid/expired
4. Attach decoded payload to request scope for downstream use

## Layered Architecture

```
HTTP request
     │
     ▼
Route handler         wobsongo/api/routes/*.py
  - parse & validate request body / query params
  - call service method with domain types
  - map result to response schema
  - return HTTP status code
     │
     ▼
Service               wobsongo/core/services/*.py
  - business logic (state machine, key generation, verdict aggregation)
  - calls repo / storage / LLM via protocol interfaces
  - raises domain exceptions → route maps to HTTP errors
     │
     ▼
Repository / Storage  wobsongo/adapters/*.py
  - SQL queries only, no logic
  - one method per operation
```

### Route layer — only HTTP concerns

```python
# wobsongo/api/routes/jobs.py
@post("/api/v3/jobs", status_code=201)
async def create_job(
    data: CreateJobRequest,
    job_service: JobService,
) -> JobCreatedResponse:
    return await job_service.create_job(title=data.title, filename=data.filename)
```

### Service layer — business logic only

```python
# wobsongo/core/services/job_service.py
class JobService:
    def __init__(self, job_store: JobStoreProtocol, storage: ObjectStorageProtocol):
        ...

    async def create_job(self, title: str, filename: str) -> JobCreated:
        key = f"documents/{uuid4()}/{filename}"
        job = IngestionJob(id=uuid4(), status="pending", title=title,
                           filename=filename, storage_key=key,
                           created_at=now_iso())
        await self._job_store.save_job(job)
        upload_url = self._storage.generate_upload_url(key)
        return JobCreated(job_id=job.id, storage_key=key, upload_url=upload_url)

    async def retry_job(self, job_id: UUID) -> IngestionJob:
        job = await self._job_store.get_job(job_id)
        if job is None:
            raise NotFoundError("Job not found")
        if job.status != "failed":
            raise ConflictError("Job is not in failed state")
        await self._job_store.update_job(
            job_id, status="pending",
            error_message=None, started_at=None, finished_at=None,
        )
        return await self._job_store.get_job(job_id)
```

## New Protocols — `wobsongo/core/ports.py`

```python
class DocumentStoreProtocol(Protocol):
    async def save_document(self, doc: SourceDocument) -> None: ...
    async def get_document(self, doc_id: UUID) -> SourceDocument | None: ...
    async def get_document_by_hash(self, content_hash: str) -> SourceDocument | None: ...
    async def list_documents(self, page: int, page_size: int) -> tuple[list[SourceDocument], int]: ...
    async def delete_document(self, doc_id: UUID) -> None: ...
```

`JobStoreProtocol` and `ObjectStorageProtocol` are defined in `worker-plan.md`.  
Existing `RepositoryProtocol` stays for backward compat.

## Testing Strategy

Services are tested in isolation using stub repos — no real DB, no network.

```python
# wobsongo/adapters/db_stub.py
class StubDocumentStore:
    def __init__(self) -> None:
        self._docs: dict[UUID, SourceDocument] = {}

    async def save_document(self, doc: SourceDocument) -> None:
        self._docs[doc.id] = doc

    async def get_document(self, doc_id: UUID) -> SourceDocument | None:
        return self._docs.get(doc_id)

    async def list_documents(self, page: int, page_size: int) -> tuple[list[SourceDocument], int]:
        items = list(self._docs.values())
        start = (page - 1) * page_size
        return items[start : start + page_size], len(items)

    async def delete_document(self, doc_id: UUID) -> None:
        self._docs.pop(doc_id, None)
```

Test pattern:

```python
# tests/services/test_job_service.py
async def test_create_job_generates_upload_url() -> None:
    service = JobService(job_store=StubJobStore(), storage=StubStorage())
    result = await service.create_job(title="WHO Guide", filename="who.pdf")
    assert result.status == "pending"
    assert result.upload_url.startswith("stub://")
    assert "who.pdf" in result.storage_key

async def test_retry_non_failed_job_raises_conflict() -> None:
    store = StubJobStore()
    job = IngestionJob(id=uuid4(), status="processing", ...)
    await store.save_job(job)
    service = JobService(job_store=store, storage=StubStorage())
    with pytest.raises(ConflictError):
        await service.retry_job(job.id)
```

## Verification

```bash
# 1. Install
uv pip install -e ".[storage]"  # boto3
# PyJWT is a core dep, installed automatically

# 2. Run tests
uv run pytest tests/services/ tests/api/

# 3. Start API
uv run python main.py

# 4. Get token
TOKEN=$(curl -s -X POST http://localhost:8000/api/v3/auth/token \
  -H "Content-Type: application/json" \
  -d '{"password":"adminpass"}' | jq -r .access_token)

# 5. Submit a job
curl -X POST http://localhost:8000/api/v3/jobs \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"WHO Guide","filename":"who.pdf"}'

# 6. List documents (after worker completes)
curl http://localhost:8000/api/v3/documents \
  -H "Authorization: Bearer $TOKEN"

# 7. Verify a claim
curl -X POST http://localhost:8000/api/v3/verify \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text":"Letrozole is better than clomiphene for PCOS."}'

# 8. Check OpenAPI spec
curl http://localhost:8000/schema | jq .
```
